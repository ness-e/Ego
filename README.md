# Ego

**Tu yo operativo. Capacidad ampliable por módulos, un solo cerebro.**

Ego es una aplicación de escritorio (Electron, solo desktop) y sistema operativo personal para fundadores solitarios, indie hackers y creadores, construida sobre VantaDB como memoria persistente local-first.

## Docs

- PRD completo (histórico): `docs/prd/investigacion-de-diseño/Ego_PRD_Blueprint_v2.1.md` (consolidado como PRD + Blueprint v1.0; no editar)
- Índice docs: `docs/index.md`
- OpenCode adaptado: `.opencode/`

## Principio de construcción

1. Base de conocimiento P0
2. Memoria persistente vía `EgoMemoryAdapter`
3. Cuarentena, TTL, supersede y grafo
4. CRM/soporte básicos
5. Jev y agentes solo después de validar memoria
