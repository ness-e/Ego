# Anti-Generic Guard & The Cliché-Breaker Protocol

Este documento define las reglas de auditoría y los procedimientos de intervención activa para detectar y romper la convergencia hacia clichés visuales en el diseño de personajes por código.

---

## 2. El Protocolo Cliché-Breaker (Intervención Estructural Obligatoria)

Al detectar un diseño genérico, **está terminantemente prohibido intentar arreglarlo cambiando el color de acento o añadiendo más partículas**. Se deben aplicar **al menos 2 Cambios Estructurales Obligatorios** seleccionados de la siguiente matriz:

```
                   [ MATRIZ DE INTERVENCIONES ESTRUCTURALES CLICHÉ-BREAKER ]
         ┌───────────────────────────────────┬───────────────────────────────────┐
         │ CAMBIO ESTRUCTURAL 1: SILUETA     │ CAMBIO ESTRUCTURAL 2: MATERIAL    │
         │ Reemplazar esferas por poliedros  │ Reemplazar plástico de vinilo por │
         │ facetados, monolitos angulares o  │ cerámica kintsugi, madera tallada │
         │ estructuras laminares huecas.     │ o papel plegado con aristas duras.│
         ├───────────────────────────────────┼───────────────────────────────────┤
         │ CAMBIO ESTRUCTURAL 3: CINEMÁTICA  │ CAMBIO ESTRUCTURAL 4: EXPRESIÓN   │
         │ Reemplazar flotación senoidal por │ Sustituir visor OLED por ranuras  │
         │ pasos mecánicos con impacto o     │ analíticas, monóculo de lente o   │
         │ animación escalonada a 12 FPS.    │ rostro asimétrico no antropomorfo.│
         └───────────────────────────────────┴───────────────────────────────────┘
```

## 3. Lista de Chequeo Anti-Genericidad Previa al Código

Antes de aprobar cualquier especificación de personaje:
- [ ] ¿El personaje sigue siendo reconocible si se apagan todas las luces emisivas y el visor?
- [ ] Si se coloca este personaje junto a otros tres personajes tecnológicos del mercado, ¿alguien podría confundirlos?
- [ ] ¿La silueta tiene aristas, asimetrías o huecos que rompan la masa esférica convencional?
- [ ] ¿El material seleccionado comunica la naturaleza real del producto (robusto, ágil, táctil, editorial)?
- [ ] ¿El movimiento transmite peso, fricción y resistencia con el entorno en lugar de flotar ingrávido?
