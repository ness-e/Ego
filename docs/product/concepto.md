# Concepto de Producto: Ego

## Definición canónica

Ego es un Sistema Operativo Cognitivo (SOC) diseñado para creadores independientes, profesionales y organizaciones que necesitan construir y operar un proyecto completo de manera inteligente y unificada. No es una simple herramienta de chat o un conjunto inconexo de agentes de IA (que en Ego se denominan Sub-Egos); es la infraestructura cognitiva y operativa que integra diversas capacidades alrededor de un proyecto vivo. 

A través de un entorno de memoria compartida, Ego coordina Sub-Egos especializados con responsabilidades, contexto, capacidades, herramientas y reglas de comportamiento, permitiendo a los usuarios delegar, colaborar y automatizar tareas complejas, gestionando todas las áreas operativas desde una única interfaz conectada.

## Definición corta

Ego es un Sistema Operativo Cognitivo que convierte a una persona en una organización asistida por IA para construir y operar proyectos complejos.

## Qué administra Ego

Ego es el gestor central de:
*   Contexto
*   Memoria
*   Conocimiento
*   Objetivos
*   Tareas
*   Decisiones
*   Herramientas
*   Operaciones

## Cómo funciona

Ego opera como una organización virtual compuesta por Sub-Egos que comparten un contexto común a través de una arquitectura de memoria compartida. Ego proporciona un conjunto inicial de Sub-Egos especializados y permite crear y personalizar otros según las necesidades de cada proyecto; tanto los predefinidos como los personalizados son la misma entidad fundamental. Se apoya en un avanzado sistema de enrutamiento de modelos, garantizando que el modelo óptimo procese cada tarea según sus necesidades cognitivas.

## Comportamiento de los Sub-Egos

Los agentes de IA (internamente) en Ego se denominan Sub-Egos. No son "empleados digitales", sino "Sub-Egos especializados persistentes con responsabilidades, contexto, capacidades, herramientas y reglas de comportamiento dentro del proyecto". Todo especialista inteligente dentro de Ego es un Sub-Ego.

Ellos pueden:
*   Analizar información y recomendar acciones.
*   Detectar anomalías o necesidades operativas.
*   Reportar de forma proactiva.
*   Colaborar de manera estructurada.
*   Delegar tareas específicas a otros Sub-Egos.
*   Revisar y auditar el trabajo mutuo.
*   Participar orgánicamente cuando su área de especialización es mencionada.

## Sistema de enrutamiento de modelos

Ego incorpora un sistema de coordinación y enrutamiento (model routing) que selecciona y combina diferentes modelos para cada tarea, operando bajo roles funcionales:
*   Orquestador
*   Supervisor
*   Planificador
*   Ejecutor
*   Integrador
*   Evaluador
*   Investigador
*   Memoria / Contexto
*   Interfaz

## Modo construcción

Ego no solo administra operaciones; también permite construir proyectos de software, escribir código y configurar el entorno mediante la instalación de skills, protocolos MCP (Model Context Protocol) e integraciones, siendo completamente personalizable por el usuario.

## Audiencias

El uso de Ego no está limitado a "creadores solitarios". El criterio de adopción fundamental es la complejidad operativa del proyecto, no el número de empleados.
*   **ICP Inicial (Beachhead):** Creadores independientes, fundadores y profesionales independientes.
*   **Mercado Total:** Cualquier persona, equipo u organización que necesite construir u operar un proyecto completo desde un entorno inteligente centralizado.

## Evolución del usuario

| Etapa | Descripción |
| --- | --- |
| Independiente | Una persona utilizando Ego para multiplicar sus capacidades y gestionar el proyecto entero. |
| Colaboración externa | Incorporación de freelancers o consultores externos que interactúan con Ego. |
| Micro-equipo | Un equipo pequeño coordinando operaciones centrales mediante Ego. |
| Organización en crecimiento | Estructuras departamentales donde Ego actúa como capa de inteligencia y conexión interdepartamental. |
| Organizaciones grandes | Adopción corporativa profunda de la capa cognitiva. |

## Principio fundamental

> "Ego no debe entenderse como un chatbot, una base de conocimiento, un CRM, un gestor de tareas o una colección de agentes (Sub-Egos). Es la infraestructura cognitiva y operativa que integra estas capacidades alrededor de un proyecto vivo."
