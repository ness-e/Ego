# Guía de usuario de Ego

Ego es un Sistema Operativo Cognitivo (SOC) local-first para escritorio.
Esta guía cubre el uso diario. Detalles de arquitectura viven en la
documentación canónica (`../product/`, `../architecture/`).

## Contenido

- [Primeros pasos](./getting-started.md) — arrancar Ego, crear tu primer
  proyecto y completar tu primera tarea con un Sub-Ego.
- [Configuración de modelos (BYOK)](./configuration.md) — conectar tus
  propias API keys u Ollama local desde el panel de Configuración.
- [Conceptos clave](./concepts.md) — Chat, Canvas, Sub-Egos, memoria por
  proyecto y aprobaciones (HITL).
- [Solución de problemas](./troubleshooting.md) — síntomas comunes, causas
  y qué hacer en cada caso.

## Convenciones

- Atajos: `Ctrl+B` (mostrar/ocultar barra lateral), `Ctrl+N` (nueva
  sesión), `Ctrl+K` (buscar en memoria). En macOS, `Cmd` equivale a `Ctrl`.
- Todo lo que configures en la app se guarda localmente en tu equipo.
  Ego no envía tus datos a ningún servidor propio.
